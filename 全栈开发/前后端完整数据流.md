##Uvicorn 在中间做了什么？—— 双向翻译
Uvicorn 的核心工作就是**协议转换**,分为两步：

**① 请求阶段(HTTP → Python 对象)**

- Uvicorn 监听端口 8000,收到原始 HTTP 请求字节流
    
- 解析请求行、请求头、请求体
    
- 将解析后的数据封装成 **ASGI(异步服务器网关接口)标准**的 Python 对象
    
- 调用你的 FastAPI 应用,把 Python 对象传进去
    

**你的 FastAPI 函数里拿到的 `request` 对象,就是 Uvicorn 帮你构造好的。**

**② 响应阶段(Python 对象 → HTTP)**

- FastAPI 函数返回 Python 字典 `{"name": "Alice"}`
    
- Uvicorn 把这个字典**序列化**成 JSON 字符串
